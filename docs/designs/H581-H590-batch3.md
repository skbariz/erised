# H581–H590: Batch 3 — Regime Signal Variants + Leverage Refinements

## Context

H570 (LeverageRegimeConditional) is the new program champion at Sharpe 2.021.
Mechanism: SPY > 200d MA → cap=2.5×; bear → cap=1.0×. +0.143 Sharpe vs H559.

Batch 3 systematically extends this finding:
- Does a better regime signal (VIX, SPY-TLT corr) improve on 200d MA?
- Does three-state granularity beat binary bull/bear?
- Does H570 survive realistic borrow costs?
- Does combining Sortino/MaxDD with regime improve further?
- Can a duration filter reduce whipsaw in regime transitions?
- Does adding H576/H577 (low H001-corr) to the pool help?

All 10 runners use the same 55-strategy base pool (H570 pool) unless noted.
Canonical leverage params: tv=6.5% (H570 style), lb=20d, MDR warm-start.

## H581: VIXRegimeConditional

**Signal:** VIX level as bull/bear classifier instead of SPY 200d MA.
- Bull (VIX < 20): cap=2.5×
- Bear (VIX ≥ 20): cap=1.0×

**Why VIX?** Forward-looking fear gauge vs backward-looking price MA. VIX spike precedes market crash rather than lagging it. Should give faster bear detection → better MaxDD.

**Expected behavior:**
- 2000-2002: VIX spikes early → faster de-leveraging than MA
- 2008-2009: VIX > 20 entire period → bear regime throughout
- 2020 COVID: VIX spikes to 80 then recovers → short bear period
- 2013-2017: VIX mostly < 20 → stays in bull

**Success criteria:** Sharpe ≥ 1.9; MaxDD < -8.0%; CI lower > 1.5
**Falsification:** If MaxDD same or worse than H570 (−7.50%), VIX is not better than MA for bear detection.

## H582: ThreeStateRegimeLeverage

**Signal:** Three states combining SPY 200d MA + VIX:
- Strong bull: SPY > 200d MA AND VIX < 20 → cap=3.0×
- Neutral: SPY > 200d MA XOR VIX < 25 → cap=1.5×
- Bear: SPY < 200d MA AND VIX ≥ 25 → cap=0.75×

**Why three states?** Binary bull/bear misses the "calm bull" period where both signals confirm safety. Cap=3.0× in confirmed bull captures more return. Bear=0.75× (not 1.0×) provides stronger downside protection than H570.

**Expected behavior:** Better CAGR in multi-year bull periods (e.g., 2013-2019); tighter MaxDD in confirmed bear (2008-2009, 2022).

**Success criteria:** Sharpe ≥ 2.1; MaxDD < -7.0%; CAGR ≥ 13%
**Falsification:** If Sharpe ≤ H570's 2.021, three-state doesn't add value over binary.

## H583: RegimeSortinoLeverage

**Signal:** H570 regime-conditional caps + downside vol (semi-deviation) for vol targeting.
- Same bull/bear caps as H570 (2.5×/1.0×)
- Vol estimate: semi-deviation of daily returns (only negative returns used)

**Why Sortino vol?** H567 showed downside vol < total vol in bull markets → higher avg leverage → better CAGR. Combining with regime should amplify this in bull and still protect in bear.

**Expected behavior:** CAGR ≥ H570's 12.79% (more leverage in bull); MaxDD similar or better.

**Success criteria:** Sharpe ≥ 2.1 OR (Sharpe ≥ 2.0 AND CAGR ≥ 14%)
**Falsification:** If CAGR same as H570 and Sharpe ≤ 2.0, downside vol adds no value to regime conditioning.

## H585: SPYTLTCorrRegimeConditional

**Signal:** SPY-TLT 60d rolling correlation as regime indicator (H097 mechanism).
- Positive corr → stocks and bonds moving together = crisis/bear: cap=1.0×
- Negative corr → flight to quality relationship = normal: cap=2.5×

**Why SPY-TLT corr?** Always computable (no data gaps), captures flight-to-safety dynamics that lead market stress. H097 showed this signal produces Sharpe 0.992 at the base level. As a leverage gating signal, it may outperform the lagging 200d MA.

**Expected behavior:** Better drawdown control in 2008-2009 GFC (corr turns positive early); possibly faster recovery in 2020 COVID (corr normalizes quickly).

**Success criteria:** Sharpe ≥ 1.9; MaxDD < -8.0%
**Falsification:** If MaxDD worse than H570 (−7.50%), correlation signal is not better for crisis detection.

## H586: AsymmetricVolTargetRegime

**Mechanism:** Both vol target AND cap vary with regime:
- Bull (SPY > 200d MA): tv=8.0%, cap=2.5×
- Bear: tv=4.0%, cap=1.0×

**Why?** H570 only adjusts cap; the vol target stays at 6.5%. In bull markets, 8% vol target allows more leverage (avg lev higher → more CAGR). In bear, 4% vol target further de-risks beyond just capping.

**Expected behavior:** Higher CAGR than H570 in bull-dominated periods; tighter MaxDD in bear.

**Success criteria:** Sharpe ≥ 2.05 OR CAGR ≥ 14%
**Falsification:** If CAGR < H570 (12.79%), dual-parameter regime doesn't outperform single-cap regime.

## H587: RegimeConditionalCalmar

**Mechanism:** H570's bull/bear regime-conditional caps, but optimize leveraged Calmar ratio instead of leveraged Sharpe.
- Same caps: bull=2.5×, bear=1.0×; tv=6.5%/lb=20d
- Objective: maximize CAGR_lev / |MaxDD_lev|

**Why?** H558 (pure Calmar objective) found Calmar 1.802 but Sharpe only 1.731 — Calmar optimization trades Sharpe for CAGR. With regime conditioning adding bear protection, the Calmar objective may now be able to push CAGR further. Tests if H570's regime mechanism enhances Calmar the same way it enhances Sharpe.

**Success criteria:** Calmar ≥ 2.0; Sharpe ≥ 1.8
**Falsification:** If Sharpe < H558 (1.731) or Calmar < H558 (1.802), regime doesn't help Calmar optimization.

## H589: DurationFilteredRegime

**Mechanism:** H570's 200d MA regime with persistence filter:
- Regime only switches after N=10 consecutive days in new regime
- Prevents whipsaw when market oscillates around 200d MA

**Why?** When SPY oscillates near its 200d MA, H570's daily regime switch creates unnecessary cap changes. A duration filter smooths this, reducing transaction-equivalent costs from leverage changes.

**Expected behavior:** Fewer regime switches → slightly higher Sharpe from reduced whipsaw; same bull fraction (most bear regimes last many months).

**Success criteria:** Sharpe ≥ H570's 2.021 (even marginal improvement validates the filter)
**Falsification:** If Sharpe < H570, the persistence filter delays beneficial switches more than it prevents harmful ones.

## H590: RegimeConditionalMaxDDPenalty

**Mechanism:** H570's regime-conditional caps + MaxDD penalty in bear regime:
- Bull: pure lev-Sharpe objective (same as H570)
- Bear: lev-Sharpe − 0.5 × penalty × (MaxDD / 0.10)² objective
- Tests if adding drawdown protection in bear regime further reduces MaxDD beyond just capping leverage

**Why?** In bear regimes, the portfolio with H570 still optimizes for Sharpe. Adding a MaxDD penalty in bear regime pushes SLSQP to find a more defensive portfolio composition when leverage is already limited.

**Expected behavior:** Slightly lower Sharpe than H570, but tighter MaxDD in bear periods.

**Success criteria:** MaxDD < -6.5% (better than H570's −7.50%) while Sharpe ≥ 1.90
**Falsification:** If MaxDD doesn't improve substantially (< 0.5pp), the MaxDD penalty adds no value over pure regime cap limiting.
