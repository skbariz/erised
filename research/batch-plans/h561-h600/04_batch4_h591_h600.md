## H595 — MaxDD-Constrained Champion (Institutional DD Profile)

**Signal:** Apply H564's approach (MaxDD-constrained lev-Sharpe) with optimal params and expanded
pool, targeting MaxDD_lev ≤ 7%.
**Hypothesis:** H559 (1.879, -9.73% DD) meets institutional Sharpe bars but marginally fails the
"low MaxDD" institutional bar some clients set at -7%. Finding the portfolio that maximizes
lev-Sharpe while guaranteeing MaxDD ≤ 7% is the formal solution to this institutional constraint.

**From H564 Pareto analysis:** There's a smooth tradeoff from -9.73% (H559) to -7.25% (lev-
Composite) costing 0.117 Sharpe. With the expanded pool and better params, this tradeoff may
have shifted — perhaps we can achieve -7% DD at 1.80+ Sharpe.

**Implementation:**
```python
def neg_dd_constrained_lev_sharpe(w, dd_limit=0.07, penalty=20.0):
    r_base = mat @ w
    r_lev = apply_vol_leverage(r_base, target_vol=best_tv, cap=best_cap)
    sh = compute_sharpe(r_lev)
    dd = abs(compute_maxdd(r_lev))  # positive
    pen = penalty * max(0, dd - dd_limit)
    return -(sh - pen)
```

**Success criteria:** Sh_lev > 1.80 AND MaxDD_lev > -7.5%. This would be the first strategy
to simultaneously achieve 1.8+ Sharpe AND -7.5% MaxDD — a new Pareto frontier point.
